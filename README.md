## 当前在做

LabLens v0.8 将分析计划扩展到导入的实验数据：模型输入、预览和结果绑定同一快照，发送数据前明确选择，切换数据后清除旧草稿和许可。247项工程测试通过，47份历史结果兼容，新增导入/执行/离线复核演示。

3份合成快照、6题各两次真实调用：8/12通过预声明合同，4条完整Pareto错误在两轮后被规则拒绝，修正仍失败。A/B用相同ID与不同数值检验隔离，C检查token单位；公开全部失败、费用和冻结源码。自动合同检查与助手复核不是独立人工审核或外部真实实验泛化。
